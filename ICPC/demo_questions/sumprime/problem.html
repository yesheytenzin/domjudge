Problem E: Sum of Prime Numbers up to N HARD

Description

Calculate the sum of all prime numbers less than or equal to N.

Input Format

  • Single integer N (2 ≤ N ≤ 10000)

Output Format

Integer representing the sum of all primes ≤ N

Example

Input:
10
Output:
17

Explanation

Primes ≤ 10 are: 2, 3, 5, 7

Sum = 2 + 3 + 5 + 7 = 17

Test Cases

  • Test 1: primes ≤ 10 → 2+3+5+7 = 17
  • Test 2: primes ≤ 20 → 77
  • Test 3: primes ≤ 2 → 2
