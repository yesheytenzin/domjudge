Problem B: Convert Celsius to Fahrenheit EASY

Description

Convert a temperature from Celsius to Fahrenheit.

Formula: F = (C × 9/5) + 32

Input Format

  • Single integer C (temperature in Celsius, -1000 ≤ C ≤ 1000)

Output Format

Integer temperature in Fahrenheit

Example

Input:
100
Output:
212

Note

Output should be rounded to nearest integer.

Test Cases

  • Test 1: 100°C = 212°F
  • Test 2: 0°C = 32°F
  • Test 3: -40°C = -40°F
