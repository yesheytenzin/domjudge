Problem C: Count Vowels in a String MEDIUM

Description

Count the number of vowels (a, e, i, o, u) in a given string.

Input Format

  • A single line containing a string (length 1 to 1000)
  • String contains only lowercase and/or uppercase English letters

Output Format

Integer representing the count of vowels (case-insensitive)

Example

Input:
Hello World
Output:
3

Explanation

Total = 3 vowels: 'e', 'o', 'o'

Test Cases

  • Test 1: "Hello World" → 3 vowels
  • Test 2: "AeIoU" → 5 vowels
  • Test 3: "bcdfg" → 0 vowels
