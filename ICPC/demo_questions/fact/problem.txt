================================================================================
PROBLEM D: FACTORIAL USING FUNCTION                               [MEDIUM]
================================================================================

Difficulty: 🟡 YELLOW - Medium

Description:
Calculate the factorial of a non-negative integer N.

Definition:
- N! = N × (N-1) × (N-2) × ... × 2 × 1
- 0! = 1

Input Format:
- Single non-negative integer N (0 ≤ N ≤ 12)

Output Format:
- Integer representing N!

Example:
Input:          Output:
5               120

Explanation: 5! = 5 × 4 × 3 × 2 × 1 = 120

Test Cases:
- 1.in / 1.out: 5! = 120
- 2.in / 2.out: 0! = 1
- 3.in / 3.out: 10! = 3628800
