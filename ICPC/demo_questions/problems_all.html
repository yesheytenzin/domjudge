Problem A: Sum and Average of N Numbers EASY

Description

Given N integers, calculate their sum and average.

Input Format

  • First line: Integer N (1 ≤ N ≤ 1000)
  • Second line: N space-separated integers

Output Format

Two values separated by a space: sum and average (round down to integer)

Example

Input:
5
1 2 3 4 5
Output:
15 3

Test Cases

  • Test 1: 5 numbers (1,2,3,4,5) → sum=15, avg=3
  • Test 2: 3 numbers (10,20,30) → sum=60, avg=20

Problem B: Convert Celsius to Fahrenheit EASY

Description

Convert a temperature from Celsius to Fahrenheit.

Formula: F = (C × 9/5) + 32

Input Format

  • Single integer C (temperature in Celsius, -1000 ≤ C ≤ 1000)

Output Format

Integer temperature in Fahrenheit

Example

Input:
100
Output:
212

Test Cases

  • Test 1: 100°C = 212°F
  • Test 2: 0°C = 32°F
  • Test 3: -40°C = -40°F

Problem C: Count Vowels in a String MEDIUM

Description

Count the number of vowels (a, e, i, o, u) in a given string.

Input Format

  • A single line containing a string (length 1 to 1000)
  • String contains only lowercase and/or uppercase English letters

Output Format

Integer representing the count of vowels (case-insensitive)

Example

Input:
Hello World
Output:
3

Test Cases

  • Test 1: "Hello World" → 3 vowels
  • Test 2: "AeIoU" → 5 vowels
  • Test 3: "bcdfg" → 0 vowels

Problem D: Factorial Using Function MEDIUM

Description

Calculate the factorial of a non-negative integer N.

Definition

  • N! = N × (N-1) × (N-2) × ... × 2 × 1
  • 0! = 1

Input Format

  • Single non-negative integer N (0 ≤ N ≤ 12)

Output Format

Integer representing N!

Example

Input:
5
Output:
120

Test Cases

  • Test 1: 5! = 120
  • Test 2: 0! = 1
  • Test 3: 10! = 3628800

Problem E: Sum of Prime Numbers up to N HARD

Description

Calculate the sum of all prime numbers less than or equal to N.

Input Format

  • Single integer N (2 ≤ N ≤ 10000)

Output Format

Integer representing the sum of all primes ≤ N

Example

Input:
10
Output:
17

Explanation

Primes ≤ 10 are: 2, 3, 5, 7
Sum = 2 + 3 + 5 + 7 = 17

Test Cases

  • Test 1: primes ≤ 10 → 2+3+5+7 = 17
  • Test 2: primes ≤ 20 → 77
  • Test 3: primes ≤ 2 → 2

Problem F: Armstrong Number Check HARD

Description

Check if a given positive integer is an Armstrong number (narcissistic number).

Definition

An Armstrong number is a number that is equal to the sum of cubes of its digits.

Generalized: For an n-digit number, sum of (digit^n) = original number.

Examples

  • 153: 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✓
  • 124: 1³ + 2³ + 4³ = 1 + 8 + 64 = 73 ≠ 124 ✗

Input Format

  • Single positive integer N (1 ≤ N ≤ 1000000)

Output Format

"yes" if Armstrong number, "no" otherwise (lowercase)

Example

Input:
153
Output:
yes

Test Cases

  • Test 1: 153 → yes (1³+5³+3³=153)
  • Test 2: 124 → no (1³+2³+4³=73)
  • Test 3: 407 → yes (4³+0³+7³=407)
