Problem A: Sum and Average of N Numbers EASY

Description

Given N integers, calculate their sum and average.

Input Format

  • First line: Integer N (1 ≤ N ≤ 1000)
  • Second line: N space-separated integers

Output Format

Two values separated by a space: sum and average (round down to integer)

Example

Input:
5
1 2 3 4 5
Output:
15 3

Constraints

  • All numbers are integers
  • Average should be floor of actual average

Test Cases

  • Test 1: 5 numbers (1,2,3,4,5) → sum=15, avg=3
  • Test 2: 3 numbers (10,20,30) → sum=60, avg=20
